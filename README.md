# Tano's Koine Academy — Static Vercel Edition

A dependency-free Biblical Greek learning website containing 23 lessons, 148 vocabulary entries, alphabet practice, flashcards, parsing drills, interlinear readings, assignments, quizzes, video resources, games and browser-based progress.

## Deployment

Import this folder into Vercel using the **Other** framework preset. No build command, install command, output directory, environment variables or database are required.
